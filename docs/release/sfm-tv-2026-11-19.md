# SFM TV — one-screen selection and remote usability

## Scope

Owner request: make Save and view reachable by remote, keep market customization
inside one TV screen, remove the duplicate lower Market hours entry, move My
channels to the upper controls with readable labels, and show headlines together
instead of a one-item news carousel.

Base: `1945131821fac99c60122e957c14292891b85723`.
Android preview: version `1.0.20`, build `26`.

- Embedded session selection has its own focus scope and Back destination. All
  81 clock exchanges use one grid across the 900×500 through 1920×1080 TV layouts, with
  compact names, flags, selection indicators and a fixed Save action.
- The market customizer uses a compact directory and fixed editing controls.
  Arrow keys follow visible rows, OK opens the market controls, and Back returns
  to the chosen market before closing its dialog.
- Upper actions have visible localized names; the footer no longer repeats
  Market hours or My channels.
- Received headlines render together with source/time and the existing full
  story detail on OK. The general feed remains capped by the server at eight;
  no price, licensing, authentication, RLS or provider behavior changes.
- Android Back recognizes embedded editors as well as dialogs.

## Release status and recovery

Production promotion requires exact-head CI, browser artifact review and a
deployment readback. No physical Huawei or television remote test is claimed.
Android CI outputs remain debug preview packages, not a signed Google
Play/AppGallery release.

The Android interface is bundled at
`https://appassets.androidplatform.net/assets/index.html`; production supplies
API data, not a replacement interface. A website deployment does not update an
installed APK's layout or remote controls.

The published build 25 at `1945131` uses `com.thesfm.marketstv`, version
`1.0.19`, and an Android Debug certificate issued during its CI build. Its public
certificate SHA-256, extracted from the APK v2 signing block, is
`db963070692ebfabaa30d2b7662d35633a4e80dc2e19787e0429412ee7d6dfc3`.
The inspected APK SHA-256 matches the published asset:
`30c9a0dbd11bbea8ac6b775ec78b0d4108aaa0456a53c1e77ff30776af13dfa8`.
This records certificate identity, not an on-device update test. The current
debug publishing path does not restore that signer; an in-place update requires
a matching installed certificate and cannot be promised from a version bump.

The existing `com.thesfm.marketstv.preview` flavor is labelled **SFM TV Preview**.
The release workflow attaches its signed debug APK and checksum alongside the
existing Huawei debug APK and checksum; it never selects unsigned Release
outputs. Preview installs separately so the existing main or `.huaweitest` app
and its settings remain intact. Settings are not automatically migrated. Do not
uninstall the existing app or clear its data to install Preview. No signing
configuration, certificate or package identity is changed by this delivery step.

No migrations or account-data changes. If the UI regresses, the prior application
revision above is the rollback reference; do not reverse database state. Preserve
device settings and the existing application ID. Full production observability,
store signing and physical-device approval are outside this focused UI change.
