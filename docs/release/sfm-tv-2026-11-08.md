# SFM TV receiver and native release record

Owner: Mohammed AlQallaf. Implementation and verification: Codex, 8 November 2026.

## Candidate

PR: https://github.com/elqallaf09/thesfm/pull/350

Android WebView preview: 1.0.16/build 22, package `com.thesfm.marketstv`.
Native TV: 0.2.0/build 2, Apple bundle `com.thesfm.marketstv.native`, Android package `com.thesfm.marketstv.tvnative`.

Public Europe/category news accepts `view=headlines`, which omits price enrichment and bulk translation; normal website requests retain their previous behavior. TV persistence is scheduled after the response. Original headlines, sources, timestamps and Sharia screening status are preserved. No database migration or account authorization policy changes.

Native TV gains 25 channels, paged directories, market calendars, pairing and private portfolio sync. Tokens use platform SecureStore, requests use a fixed SFM origin, private values are cleared on backgrounding, scope changes, failed refreshes and revocation. The native client is still a test release; physical device and fresh-account approval gates remain open.
