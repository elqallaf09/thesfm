# SFM TV — سلسلة المزوّدين وTHE SFM كمصدر (2026-11-20)

## السبب الجذري للتوقف
- كانت كل شاشة تسأل Twelve Data عن كل زوج فوركس كل دقيقة، فتنتهي الحصة اليومية المجانية (800 رصيد) خلال ساعة ونصف تقريبًا بعد منتصف الليل UTC.
- هذه الأرصدة نفسها تستخدمها أسعار أسهم الخليج، فتتوقف معها.
- لم يكن هناك مخزن مشترك لآخر سعر موثّق إلا للمؤشرات.

## السلسلة بعد التغيير
| المجموعة | الترتيب |
| --- | --- |
| الفوركس | Tiingo FX (طلب واحد لكل صفحة، إن وُجد `TIINGO_API_KEY`) ← Yahoo ← Twelve Data ← ECB ← Frankfurter ← مخزن THE SFM |
| المؤشرات | FMP ← Twelve Data (FTSE/N225) ← EODHD ← Yahoo ← مخزن THE SFM ← أرشيف `sfm_market_observations` |
| بقية الأصول | السلسلة الحالية لكل أصل ← مخزن THE SFM |

- **مخزن THE SFM:** كل سعر موثّق يُحفظ في `trader_cache` بمصدره ووقته الأصليين. عند انقطاع كل المزوّدين يُعرض بوسم "قديم" فقط.
- **الجامع المركزي:** المسار `/api/tv/collect` يعمل كل 5 دقائق (Vercel Cron مع `CRON_SECRET`). يجلب المؤشرات والسلع وأهم 12 زوج فوركس مرة واحدة، فتقرأ كل الشاشات من الكاش المشترك.
- كل مزوّد يتوقف عند نفاد حصته (429) حتى تتجدد، ويجيب التالي تلقائيًا.
