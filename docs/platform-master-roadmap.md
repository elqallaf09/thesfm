# THE SFM — خارطة المنتج الموحدة

تاريخ المطابقة: 2026-09-19. أساس مراجعة الكود: `c72b593700080dcda498741df8f287943dc2bda9`.
هذه الوثيقة تجمع قائمة المالك كاملة وتربطها بالتنفيذ؛ وهي مرجع ترتيب المنتج. تبقى تقارير المراحل المتخصصة أدلة تفصيلية، ولا تستبدلها هذه الوثيقة.

## كيفية قراءة الحالة

- **موجود**: يوجد تنفيذ محدد في المصدر؛ لا يعني أن جميع سيناريوهاته اجتازت قبول Production.
- **جزئي**: توجد بنية أو وظيفة مرتبطة، وما زالت متطلبات محددة غير مكتملة.
- **مخطط**: محفوظ هنا؛ لم يُثبت تنفيذ متكامل في مراجعة المصدر الحالية.
- **تحقق مطلوب**: لا توجد نتيجة حالية كافية لإعلان الهدف محققًا.
- **Future Labs**: خارج الخطة الأساسية.

لا تُحوَّل الحالة إلى «مكتمل إنتاجيًا» إلا بدليل مرتبط بالكومِت، واختبار رحلة المستخدم، وبيانات صحيحة، وعزل الحسابات، والتحقق الحي عند الحاجة. التقارير القديمة ليست قياسًا للنسخة الحالية. لا تُحسب نسبة اكتمال عامة من عدد الملفات أو الصفحات.

## 5. ترتيب التنفيذ والبوابات

1. **استقرار النظام**: استكمال مصادر البيانات المثبتة وحدود الحصص، منع الانحدار، قياسات الأداء والحمل والعزل. أهداف 95+/100 تبقى منفصلة عن حدود CI الحالية.
2. **UX**: تشخيص واضح، استعادة أي Widgets اختفت، معالجة رسوم/أخبار ناقصة، اتساق الإدخالات والكروت وTrader Light Mode.
3. **Workspace Architecture**: إغلاق حفظ الطي والثبات بعد refresh، ثم قبول الهاتف/اللوحي/الكيبورد والهوية الفرعية.
4. **توحيد التحليلات والذكاء الاصطناعي**: تحسين القدرات العشر داخل الطبقة المشتركة، مصدر حي، محادثة/مقارنة/PDF/جلسات؛ الأوامر تأتي بعقود صلاحيات وتدقيق.
5. **الفحص الشرعي**: استكمال الأدلة والمنهجيات والتقارير والتحقق الحي.
6. **مركز التنبيهات الذكي**: مصفوفة أحداث وقنوات وتفضيلات ثم إرسال قابل للتحقق؛ لا اختبار رسائل للمستخدمين الحقيقيين بلا طلب.
7. **التوسع والتطبيقات**: Teams/SFMer/الأتمتة/Marketplaces/التكاملات وiOS بعد تثبيت العقود الأساسية.
8. **التدقيق النهائي قبل الإطلاق**: [قائمة الإصدار](release/release-checklist.md)، backup/restore، auth/RLS، الفوترة، accessibility، الأداء، المراقبة، canary وrollback.
9. **Roadmap 2.0 بعد الإطلاق**: ترتيب بقياسات الاستخدام ونجاح المهام وتكلفة الخدمة، لا بعدد المزايا فقط.

### قواعد التكلفة وحفظ الخطة

- لا يُشغّل اختبار 100/500/1000 على Production أو على بيانات المستخدمين. الأداة الجديدة محلية وبوضع dry-run افتراضي؛ تشغيلها لا يساوي شهادة سعة.
- لا شراء مزود أو خطة أو إرسال رسائل للمستخدمين ضمن تدقيق خارطة الطريق.
- تجميع التغييرات وفحوص محلية ثم معاينة إصدار محددة عند الحاجة؛ تبقى معاينات فروع التطوير معطلة. تحديث الوثيقة وحده لا يحتاج معاينة بصرية.
- كل دفعة تحدّث الحالة والدليل والمتبقي. أُضيفت هذه القائمة كاملة الآن؛ تسجيل ميزة كمخطط ليس تنفيذًا لها.
- [خارطة الذكاء الاقتصادي](economic-intelligence-roadmap.md) تتبع تفاصيل Phase 7؛ [متابعة المصادر](evidence-source-reliability-2026-09-19.md) تحفظ حدود الإصدار السابق؛ لا تعني أرقام المراحل تقدمًا مكتملًا على كل محاور المنتج.
