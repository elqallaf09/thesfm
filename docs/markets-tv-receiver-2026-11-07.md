# SFM TV receiver channels

Continues the opening-countdown and private-portfolio work in PR #346. The channels menu now has five numbered broadcasts: all stocks, technology-stock news, Boursa Kuwait, market hours, and My investments. Keys 1–5 and supported ChannelUp/ChannelDown events select them without intercepting editable fields or open dialogs. The chosen broadcast survives reload and paired-device settings synchronization. Saved custom channels retain their actual view as well as market settings and instrument choices; legacy presets still restore their previous mode.

The all-stock channel uses the existing exchange directory and quote API, shows one bounded batch, and moves every 40 seconds. Each exchange receives a turn before the next cycle; a cursor per exchange continues its subsequent batch. Selecting one exchange cycles that exchange alone. Provider errors and source retry windows stop automatic batch changes. Quote refresh remains 30 seconds when the source permits. Prices retain currency precision, source, original observation time, closed/delayed/stale status, and a visible update flash. Missing values remain unavailable. The previously excluded exchange remains excluded.

Boursa Kuwait uses only its qualified directory and quote identities alongside Kuwait-filtered news. Technology news requires resolved technology-stock entities and retains original-language headlines, following the website feed without an all-words topic or native-interface-language restriction. News scopes have separate cache and in-flight keys for each interface language/channel, retain publisher and publication time, refresh every three minutes, and never substitute general headlines into a scoped channel. Responses identify their news channel; clients reject unscoped older-server responses until the server update deploys. Bounded headline pages rotate every 40 seconds and respect media pause. Full news opens its original-source QR. The existing worldwide hours directory and schedules are reused; opening the market-hours channel selects the full directory only when the owner has no saved subset.

My investments reuses the read-only paired-device endpoint and website record normalization introduced earlier in this PR. Account records synchronize every 15 seconds. This is saved-record synchronization, not a new real-time exchange-price entitlement. Original valuations, currency coverage and missing FX remain explicit; no financial write, schema migration, persistent holdings cache, or shared portfolio cache is introduced.

Receiver panels are lazy-loaded for the website and bundled for offline-shell clients. Layouts reserve a fixed television canvas, with prominent prices and complete source evidence, for Arabic/English/French from 540p through 4K. Touch/mobile layouts reflow separately. Existing overview scenes, strips, settings, pairing and saved custom channels remain accessible.

## Validation and distribution

Focused receiver browser coverage verifies scoped feeds, remote numbers/channel commands, modal isolation, reload persistence, exact 40-second exchange rotation, remembered batches, provider retry windows, missing values, KWD precision and geometry/text sizing across languages and screen sizes. Synthetic financial values occur only in isolated test fixtures. Existing packaged checks cover private portfolio refresh/revocation, market countdown transitions, all 81 schedules, news/movers and prior screens. Final local and hosted CI results are recorded on the pull request.

Persistence cases serve the actual packaged files at Android's WebViewAssetLoader HTTPS origin through isolated browser routes, preserving the real origin/storage contract across reloads. Other packaged cases retain direct-file coverage. Reload assertions wait for the selected channel to render before navigating away; they do not assume dispatching a key means React has processed it.

Android source advances to 1.0.13 / versionCode 19. The separate Huawei test APK retains com.thesfm.marketstv.huaweitest and the previous test certificate; it is not a store release. Its unchanged native shell is reused with the newly built web assets, and signature/alignment, native DEX identity and every packaged web asset must be verified before delivery. A physical television and the owner’s private holdings are not represented as tested devices/fixtures.
