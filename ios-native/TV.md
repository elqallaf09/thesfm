# THE SFM TV for Apple TV

`TheSFMtv` is an Apple TV target in `TheSFM.xcodeproj` with bundle identifier `com.thesfm.tv` and scheme `TheSFMtv`.

It starts with a remote-friendly native channel surface. The existing Android/Huawei TV app, LG webOS package, and Samsung Tizen package remain separate vendor builds. Live TV data and pairing will be added only through the existing protected TV APIs and validated on physical hardware.
